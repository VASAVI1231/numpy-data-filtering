# NumPy Data Filtering

### Objective
The objective of this project is to practice Boolean indexing and numerical filtering using NumPy.

### Technologies Used
- Python
- NumPy
- Google Colab

### Description
In this project, a NumPy array containing student marks is created. Boolean conditions are used to filter values above, below, and equal to specified thresholds.

### Operations Performed
- Values above 50
- Values below 50
- Values equal to 50
- Values above 60
- Values below 40
- Values greater than or equal to 75
- Values less than or equal to 50

### Key Concept
Boolean indexing is used to select only the elements that satisfy a given condition.

Example:
python
above_50 = marks[marks > 50]
